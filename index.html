Content system

Blog, Instagram and LinkedIn: planned, produced and tracked in one place.

How it's built

One repository, scheduled jobs and a console. Built and run with Claude Code and GitHub Actions; people stay where judgement matters.

01

One source

A Git repository holds the voice, product truth, messaging and the skills every piece is written with. Content conforms to the system, not the other way around.

02

Scheduled jobs

14 GitHub Actions workflows produce, check and ship: the monthly Blog run, the daily Framer check, the Instagram and LinkedIn batches, a content health check and the console sync.

03

Blog in eight steps

Topic, brief, draft, check, German, visual run unattended about a month ahead. A morning check puts both languages into Framer three weeks out; a person reads and publishes.

04

Social from the Blog

LinkedIn runs a company and a founder voice, scheduled in Buffer weeks ahead. Instagram publishes rows of three, twice a week, from a 21-row grid rotation held in code.

05

One console

A marketing console reads state from Buffer, Framer and GA4, so what is planned, scheduled and live is visible in one place, not inferred from files.

06

People where it matters

Approving the plan, publishing in Framer and the founder's posts stay with people. Everything between runs on its own.
